## Execution policy and proof fields

Record `TEST_CANDIDATE_HEAD`, `PACKAGE_SHA256`, `INSTALLED_SERVER_HEAD`, `INSTALLED_AGENT_HEAD_<HOST>`, and `RUN_ID` for each independent track. A Git checkout or successful source CI **does not prove installed package identity**. For each allocation lane capture the public-CLI observed current run-owned live count, other concurrent E2E-owned count, intended batch size, guard result, actual assigned ports, failed-at-capacity result where legitimately tested, and post-clean inventory. Stop *that mutation* before the 31st allocated port; continue unrelated scenarios.

The 30-port budget does **not** alter product default pools, test ID counts, native allocation correctness, security policy, mandatory real traffic, or 3,600-second soak. If a test legitimately cannot prove its full assertion under this owner safety budget, keep the assertion open rather than fabricating a PASS.
